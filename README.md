# Server-Side Web Development - Assignment 1

Griffith College Dublin | BSC Stage 2 | SWD Module

## Structure

```
app/
  page.js           - Home page with navigation
  part-a/
    page.js         - Cinema ticket booking form
  part-b-c/
    page.js         - House appliance inventory form
  api/
    register/
      route.js      - POST: add appliance to inventory
    inventory/
      route.js      - GET: fetch appliances by Eircode
data/
  inventory.json    - Persisted appliance inventory
```

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
